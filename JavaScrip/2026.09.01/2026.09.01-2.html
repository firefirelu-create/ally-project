JavaScript 變數比較

const / let / var 到底有什麼不同？

三種宣告方式一次搞懂

現代 JavaScript 開發通常優先使用 const，需要重新賦值時使用 let。

const

特點：

  • 區塊作用域 Block Scope
  • 宣告時必須初始化
  • 不能重新賦值
  • 不能在同一作用域重複宣告

✓ 現代 JavaScript 優先使用

const name = "小明";
name = "小華"; // ❌ 錯誤

let

特點：

  • 區塊作用域 Block Scope
  • 可以重新賦值
  • 不能在同一作用域重複宣告
  • 宣告前不能使用

✓ 適合會改變的資料

let score = 80;
score = 90; // ✓ 可以

var

特點：

  • 函式作用域 Function Scope
  • 可以重新賦值
  • 可以重複宣告
  • 存在 Hoisting 行為

⚠ 現代程式通常不建議使用

var age = 20;
var age = 30; // ✓ 可以
